# Background Music for Breathing Exercises

## Required Audio Files

Please add the following audio files to this directory to enable background music during breathing exercises:

1. `ambient_meditation.mp3` - Ambient meditation music
2. `nature_sounds.mp3` - Natural environment sounds
3. `rain_sounds.mp3` - Gentle rain sounds
4. `ocean_waves.mp3` - Ocean waves sounds

## Audio File Requirements

- Format: MP3
- Length: Ideally 5-10 minutes (files will loop during longer sessions)
- Size: Keep under 5MB each for optimal app performance

## Where to Find These Files

You can create or purchase royalty-free meditation audio files from:
- Free sound libraries like Freesound.org
- Stock audio sites like AudioJungle or PremiumBeat
- Create your own using audio editing software

Remember to ensure you have the proper licensing rights for any audio files you include in your app.
