# Music Button Icon

Please add a `music_note.png` image to this directory. This image will be used for the music button in the breathing exercise screen.

Recommended specifications:
- Size: 48x48 px
- Format: PNG with transparency
- Style: Simple, flat icon design
- Color: The app will tint this icon, so a single color works best

You can use a music note icon from any royalty-free icon library such as:
- Material Icons
- FontAwesome
- Ionicons
- Or create your own custom icon

After adding the image, make sure to set its build action to "MauiImage" in the project properties.
